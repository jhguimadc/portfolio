# Paleta de Marca — Ecossistema JH

Paleta oficial de cores para todos os projetos do ecossistema (site, apps, ERP/PCP, materiais).
Conceito: **"planta técnica / blueprint"** — azul profundo de engenharia + acentos de energia (laranja/âmbar) e dado técnico (ciano).

## Cores base

| Token           | Hex       | Amostra | Uso principal                                   |
|-----------------|-----------|---------|-------------------------------------------------|
| `blueprint`     | `#0B2A4A` | 🟦      | Fundo primário — azul planta técnica profundo   |
| `blueprint-2`   | `#0E3358` | 🟦      | Fundo secundário / superfícies elevadas         |
| `ink`           | `#0A1929` | ⬛      | Fundo mais escuro / contraste máximo            |
| `paper`         | `#EDF1F5` | ⬜      | Fundo claro — branco-azulado frio               |
| `line`          | `#2B5580` | 🟦      | Linhas do grid / bordas                         |
| `line-soft`     | `#1B4270` | 🟦      | Bordas suaves / divisores                       |
| `spark`         | `#FF6B35` | 🟧      | Acento primário — laranja elétrico (IA/energia) |
| `spark-2`       | `#FFB627` | 🟨      | Acento secundário — âmbar                        |
| `cyan`          | `#4DD0E1` | 🟦      | Ciano técnico — dado / medida / destaque frio   |
| `white`         | `#FFFFFF` | ⬜      | Texto/superfície em alto contraste              |
| `mute`          | `#7C93AB` | ◻️      | Texto atenuado / legendas                       |

## Tons de texto (sobre fundo escuro)

| Token           | Hex       | Uso                                  |
|-----------------|-----------|--------------------------------------|
| `text-strong`   | `#B9CBDD` | Texto de destaque                    |
| `text`          | `#9DB2C7` | Texto de corpo padrão                |
| `text-soft`     | `#A9B6C6` | Texto de apoio                       |

## Diretrizes rápidas

- **Base do ecossistema:** `blueprint` (fundo) + `spark` (acento) + `cyan` (dado técnico).
- **Acentos:** use `spark` como cor de ação principal; `spark-2` e `cyan` como apoios — não competir com o laranja.
- **Contraste:** texto claro (`white` / `text-strong`) sobre fundos `ink`/`blueprint`.
- **Favicon/identidade:** iniciais **JH** — `J` em `spark`, `H` em `cyan`, sobre `blueprint` com borda `line`.
